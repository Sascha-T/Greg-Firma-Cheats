# Greg Firma Cheats
A utility mod for TerraFirmaGreg

## TerraFirmaCraft Integration
### Autosmithing
Adds a button and keybind to let you automatically smith a recipe. \
Additionally, remembers previous recipe for item type and automatically reselects it to save time.

## Alekis Nifty Ships Integration
### Auto-Steer
On a keybind, enables behaviour to automatically steers you in the direction the player is looking.
